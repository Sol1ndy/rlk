## 2. The `api.Pattern` record

```python
Pattern(id, key, label, kind, clip, phases=(1, 2, 3), elem=None, weight=None, phase_weight=None,
        cooldown=0, lead=0, recover=18, max_len=120, length=None, gates=(), replaces=None, hooks=())
```

| field | meaning |
|---|---|
| `id`, `key` | §2.1 (stable) |
| `label` | Korean name on the boss-bar sub-line while it runs |
| `kind` | `normal` (main slot, picked by the AI), `cast` (leg special: the cast slot, §6), `bg` (a short main-slot cast that hands over to a background slot, §8), `special` (B3 special, §7), `service` (transitions / sequences, started by the core) |
| `clip` | the rig clip the core plays at clock 0: a name, or `{'by': 'paw', 'map': {1: 'stomp_fl', 2: 'stomp_fr', 3: 'stomp_hl', 4: 'stomp_hr'}}` / `{'by': 'side', 'map': {1: 'tail_whip_l', -1: 'tail_whip_r'}}` (read from `#azPaw` / `#azSide` at the pick) |
| `phases` | `#azPh` values in which the AI may pick it |
| `elem` | None, or `('leg', el)` / `('tail', el)`: only for that rolled element (31 `('leg',2)`, 32 `('leg',1)`, 41 / 43 / 45 `('tail',4)`, 42 / 44 / 46 `('tail',3)`) |
| `weight` | `{zone: w}` phase-1 weights (zones §4.3); `phase_weight` `{ph: {zone: w}}` overrides; pre-filled by S1-MOD from plan §4.12, changed only by the balance fixer (`ai.WEIGHT_OVERRIDE`) |
| `cooldown` | ticks after its end before it can be picked again |
| `lead` | pre-turn ticks (0..10): `start` runs at clock −lead |
| `recover` | idle ticks after the end (plan §4.12: 14-24, heavy +6, specials +30, P3 ≥ 30) |
| `max_len`, `length` | safety end / expected end for the pattern bar (`g.set_len(t)` at runtime) |
| `gates` | AI gates: `anchor8` (anchor ≤ 8 b from the centre: P7, P8), `front35` (P3), `exit` (P7 exit test), `field_area` (skipped while the lingering area `#azFldA` ≥ 150 b²; plan §4.7 lists every field-making pick, so `ai.py` applies it to 32 and 45 always, to P1 / P2 / P5 / P5b only while their Pyro addons run (`#azLeg 1`, `#azPh ≥ 2`) and to P8 only in phase 3 (its strip); a pattern declares `field_area` and `ai.py` adds those conditions), `no_bg` (only while no background emitter lives), `no_live` (never while its own hazards / orbs live) |
| `replaces` | the id it replaces in its phases (10 replaces 5 for a fore paw in phase 3; 45 / 46 replace 4 in phase 3) |
| `hooks` | the optional files it writes: `vis pj_end pause resume reload cast ctick refresh bgtick cancel_bg b3tick stop` |

| `p/<key>/reload` | after `/reload` while active in a bg slot, as the B3 special, or as a running service 20-23 (the core first restores `#azTr` / `#azPh` / `#azBur` and the service clock; the service's `reload` re-makes what its step needs: landslide → the next wave, absorb → finish at once with the looks applied, B3 → its frame tick, plan §4.3) | body | the slot / service clock survives |

| `p/<key>/refresh` | §6 (31 only) | body | |
| `p/<key>/bgtick` / `cancel_bg` | §8 (bg slots) | body / selectors | `#azBgLT` / `#azBgTT` |
| `p/<key>/b3tick` / `stop` | §7 (specials) | body | `#azB3T` |

- Module tick order (core): clocks, brand, events, the FLANK / zone sampler, the transition queue, the B3 frame, the
  main slot (`start` / `tick` / finish), the cast slot, the bg slots L then T, the addon timers (`after`), fields, push
  request, HUD, **the rig tick last** (a clip played in `start` / `tick` renders this tick). Hazards re-aimed or resized
  from `tick` take effect in this tick's hit test (`hz/all` runs after the module tick).
- `g.end()` (= `AZ:p/end`) ends the main-slot pattern after this tick; `g.release()` (= `AZ:p/release`) marks the end of
  the dangerous part: the pattern bar hides, and **if a transition is queued** the core ends the pattern right there (it
  calls `cancel` for the harmless tail). `g.set_len(t)`.
- `max_len` is a safety net; the core finishes at `max_len` and logs it.
