## 사용자 결정 (11-10, 질문 답)
- 그로기: **경직 + 받는 피해 증가** — 몇 초 행동 불능, 그동안 받는 피해 증가, 끝나면 균형치가 다시 가득 참(시간 · 배율은 우리가 잡고
  밸런스로 맞춤).
- 균형치 감소원: **퍼펙트 패링(1칸) + 원소폭발 적중 + 강한 원소반응**, 시간이 지나면 조금씩 회복.
- 패링 불가 공격: **보스의 일부 큰 공격만**(범위 공격 · 잡기 등), 원작처럼 색 섬광으로 미리 보여 줌(글자 안내 없이 그림으로만).
- 중간 결과: GitHub `wip/*` 가지에 자주 올림.

## 리드 기본값 (사용자가 바꾸지 않으면 이대로)
- 패링 창(틱, 20 tps): F 를 누른 뒤 맞는 시점이 0-2틱 = 3단계(퍼펙트, 0.15초), 3-5틱 = 2단계, 6-9틱 = 1단계, 그 뒤 = 실패(제 피해).
  패링 뒤 짧은 재사용 대기(헛누름 연타 방지).
- 닷지 창: 누른 뒤 0-2틱에 맞을 공격 = 퍼펙트 닷지(모든 적), 일반 몹은 3-6틱도 회피(퍼펙트 아님), 보스(중간 · 챕터 · 특수 · 나루카미)는
  퍼펙트만 회피. 입력 = 지금 대쉬 입력(0번 칸 우클릭), 이동 = 지금 대쉬 모션.
- 1인칭 · 숄더뷰는 없애고 F5 위쪽 시점만 둔다(클라이언트의 F5 키는 막을 수 없음).
- 컷신: 조작 잠금 + 연출 카메라(관전 모드로 카메라 엔티티를 봄), 홍련 클로즈업, 플레이어 아바타가 검을 들고 함께 연기.
- 요이미야 · 활 무기: 삭제, 그 캐릭터로 저장된 플레이어는 루미네로.
