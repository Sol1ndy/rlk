   진짜 거리 좁히기 · 따라붙는 연속기 · 넉백은 마지막 타격만 · 몇 초씩 떠 있지 않기 · 너무 작거나 가늘지 않게).

## 리드 결정
- **전투 방식**: 새 전투(레인 C: F 패링 3단계 · 닷지, 레인 B: 균형치 12칸 · 그로기) 위에서 다시 맞춘다. 홍련의 직접 베기 · 검기는
  패링 가능, 영상에서 색 섬광이 붙는 공격(노랑 · 보라 · 파랑)은 패링 불가(퍼펙트 닷지로만) — 섬광 색 · 모양은 영상대로(가슴께의 고리 ·
  가로 빛줄기 · 별), 글자 안내 없음.
- **패턴**: 영상의 P1 · P2 패턴 전부(P-a … P-o, 궁극기 U 포함)를 기준으로 예전 A1-A10 · R1-R3 을 다시 짠다. 영상의 선딜(4-20틱)은
  위 예고 규칙에 맞게 늘린다(영상의 박자 비율은 유지). 2페이즈는 영상의 일반 패턴(보라 X, 잡기 → 공중 연타 → 내리꽂기 → 하늘 기둥,
  대각선 띠, 회전 고리 연속 → 궁극기)을 갖는다.
- **연참(A8 · A13)과 5칸 게이지**: 영상대로 — 연참의 각 베기를 **퍼펙트 패링**하면 5칸 게이지가 한 칸씩 줄고 0 이면 마지막 내리꽂기를
  튕겨 내 반격 연출로 간다(예전: 대쉬로 통과). 퍼펙트 닷지는 피해만 피하고 칸은 못 깎는다. 연참 밖에서는 이 게이지가 그녀의 공격으로
  차고 궁극기 U 가 쓴다(영상 §1.8). 실패 규칙(60 % 는 큰 피해, 5 % 는 즉사 + 경고)은 PLAN §5 를 유지.
- **균형치**: 보스 12칸(사용자). 그로기 = 쓰러졌다 일어남(레인 B 의 임시 어댑터를 이 레인이 제대로 만든다). 연참 · 컷신 중에는 균형치를
  받지 않는다.
- **컷신**(모두 조작 잠금 + 연출 카메라 + HUD 끔, 예외는 아래):
  - CS0 등장: 영상의 20숏 · 대사 11줄(101.5초). 「Shift 길게」 건너뛰기 유지. 이브는 싸우지 않는다 → 플레이어 아바타는 걸어 들어와 선다.
  - CS1 60 %: 영상의 42.5초(칼 맞대기 → 밀어냄 → 술 권하는 장면 → 꽃잎 → 반전 화면 → 분홍빛 → 가슴을 가르는 붉은 일섬 → 초원이
    붉게). 플레이어 아바타가 칼을 맞대고, 맞고, 무릎 꿇는다.
  - 반격 연출(연참 성공 뒤, 두 번): 칼 맞대기 → 붙잡기 → 갓 내려치기 → 어깨 너머로 던지기 → 걷어차기. 영상은 HUD 를 켠 채지만 조작은
    잠근다(카메라는 연출).
  - 엔딩 + 이벤트: 영상 §2.6(결투 → 공중 결투 → 칼집 → 대사 17-23 → 갓 인사) + PLAN §7 의 이벤트 · 보상(그대로).
  - 싸움 중 대사(A6 의 12번)는 잠그지 않는다.
- **조작 잠금 · 카메라**(11-06 조사 결과, 26.3 서버 jar 로 확인한 사실):
  - 방법: 플레이어를 관전 모드로 바꿔 카메라 엔티티를 `spectate` — 엔진 수준에서 마우스 · 이동 · 클릭이 막히고 회전이 부드럽다.
    카메라 = 마커 갑옷 거치대(LivingEntity 라 `camera_distance` 0 을 줄 수 있음; `marker` 엔티티는 spectate 불가, display 는 속성이
    없어 F5 에서 4칸 뒤로 물러날 수 있음), A / B 두 대(하드 컷 = 카메라 바꿔 끼우기), 틱마다 `tp … yaw pitch`.
  - `ServerPlayer.tick`: 관전 중 Shift 는 관전을 푼다(wantsToStopRiding) → 틱마다 다시 `spectate`(건너뛰기 창에서는 멈춤 허용).
    카메라 엔티티가 죽으면 저절로 자기 시점.
  - 풀기: 관전 해제 → 아바타 자리로 tp → 그녀 쪽으로 `rotate` → 게임 모드 복구(태그로 기억) → 좌석 다시 탑승(view/tick).
    모든 탈출 경로(시퀀스 끝 · 취소 · 일시정지 · /reload · 재접속 · 사망 / 로노바 · cleanup · 중단 · uninstall)에서 풀려야 한다.
    요청 방식: 저중력처럼 모듈이 틱마다 `#mbCam mb 1` 을 켜고 `mboss/main` 이 지움, `F:tick` 이 켜져 있으면 hold · 아니면 release.
  - 그녀의 리그는 `@p[gamemode=!spectator]` 를 바라봄 → 관전 중인 플레이어를 못 봄. RIGLIB(`mboss_rig_compile.mjs`)에 바라볼 대상
    선택지를 더하고(기본값 그대로 = 다른 리그 바이트 동일) 홍련은 `@e[tag=rlk_body,limit=1]`.
  - 관전의 부작용(핫바 · 하트 숨음, 숫자 키 관전 메뉴)은 받아들임. 클라이언트 F5 키는 막을 수 없음.
- **플레이어 배우**: 컷신 전용 11-디스플레이 리그(그녀의 뼈대 = 아바타 뼈대라 몸 자세는 캐릭터와 무관), 현재 캐릭터의 스킨 +
  **모두 같은 검**(사용자), 그녀의 `#sq` 시계로 같은 틱에 재생. 캐릭터 7명(요이미야 삭제됨): 리그 캐릭터 3명(스커크 · 아를레키노 ·
  나비아)은 부품 모델이 있고, 나머지 4명(루미네 · 클로린드 · 로노바 · 네페르)은 `rlk:skin/<id>` 로 부품 모델을 새로 만든다(루미네는 RP
  스킨이 없고 프로필에 박힌 텍스처뿐 → 텍스처 URL 에서 PNG 를 받거나, 안 되면 가장 가까운 스킨으로 대신하고 보고).
  아바타 엔티티는 제자리(게임 몸 · 무대 원점)에 두고 배우는 그 발밑에서 클립의 변위(≤ 2.5칸)로 움직인다.
