# 아이템 목록

- 등급: common < rare < unique(epic) < legendary < mythic
- 한 아이템에 각인은 두 개 (각인 목록은 engravings.md)
- 등급 규칙: 원신 4성 기반 = common·rare / 5성 기반 = unique·legendary / 일곱 신 + 콜롬비나 기반 = mythic. 메인 딜러 기반은 만들지 않음(서브 딜러·서포터만)
- 들여 쓴 글은 게임 안 아이템 설명과 똑같습니다. 이 파일은 게임에서 설명을 뽑아 만들기 때문에, 게임 안 설명이 바뀌면 같이 바뀝니다.
- 이름 옆의 `영문` = 아이템 id. "참고:" 줄 = 어떤 게임의 무슨 요소를 보고 만들었는지(게임에는 나오지 않음)
- 고치고 싶은 곳은 여기 글을 고친 뒤 알려 주세요. 새 아이템도 같은 모양으로 적으면 됩니다.
- 자리 바꾸기·판매: 인벤토리 첫 줄 가운데의 "◆ 인벤토리 상세" 버튼
